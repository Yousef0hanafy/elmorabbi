# MVP Scope

## INCLUDED in Phase 1 (MVP)
- **Auth:** Email/Password login.
- **Roles:** Student, Sheikh, Admin.
- **Student Dashboard:** Fixed daily checklist (5 Prayers, Quran reading checkbox, Morning/Evening Adhkar).
- **Sheikh Dashboard:** Simple list of assigned students and their current week's completion percentage.
- **Feedback:** Simple text-based direct messaging between Sheikh and assigned students.
- **Localization:** Arabic UI (RTL).
- **Responsive Web:** Mobile-first web application (PWA ready).

## EXCLUDED from Phase 1 (Do Not Build Yet)
- Native iOS/Android Apps (focus on responsive web first).
- Voice notes (add later for better UX).
- Custom task creation by students (keep it standardized for MVP).
- Complex branching learning plans.
- Granular analytics and AI predictions.
- Billing and subscriptions.
