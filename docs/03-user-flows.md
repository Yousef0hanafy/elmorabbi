# User Flows

## 1. Student Daily Log Flow
1. Receives morning/evening push notification (optional).
2. Opens App -> Lands on "Today's Responsibilities" Dashboard.
3. Taps checkboxes for completed deeds (e.g., prayers, adhkar).
4. Submits optional daily reflection.
5. Sees a progress ring update for the day.

## 2. Sheikh Review Flow
1. Opens App -> Lands on "Student Overview" Dashboard.
2. Views "Attention Needed" section (students falling behind).
3. Clicks on a student -> Views detailed weekly report.
4. Types or records a voice note of feedback.
5. Sends feedback.

## 3. Onboarding Flow (Student)
1. Receives invite link from Sheikh.
2. Signs up (Email/Password or Social Auth).
3. Completes initial assessment (current habits).
4. System generates baseline plan approved by Sheikh.
