# Feature Map

## Student Features
- **Daily Dashboard:** Checklist of today's deeds (Prayers, Fasting, Quran, Custom).
- **Progress Hub:** Weekly/Monthly charts and historical data.
- **Inbox:** Messages and feedback from the Sheikh.
- **Learning Plan:** View current goals and milestones.

## Sheikh Features
- **Roster Dashboard:** List of students with high-level status indicators (Green/Yellow/Red).
- **Intervention Alerts:** Automated highlights of students needing help.
- **Plan Manager:** Assign tasks or modify templates for students.
- **Communication Center:** Send direct messages, voice notes, or broadcast announcements.

## Admin Features
- **User Management:** Create Sheikh accounts, manage student caps.
- **Global Analytics:** Platform usage and engagement metrics.

## Cross-Cutting Features
- Full RTL & Arabic localization.
- Push Notifications / Email reminders.
